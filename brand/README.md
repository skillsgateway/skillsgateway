# Brand originals

The skillsgateway mark: an **airlock** — two gates in series over one road,
a skill entering hollow (quarantined) and leaving filled (approved and served).
It mirrors the product's pipeline: nothing is served until it has passed both
the quarantine and the approval gate.

| File | Use |
| --- | --- |
| `mark.svg` | Canonical mark. Strokes are `currentColor` (adapts to any ground); the approved node is the portal accent `#7C3AED`. |
| `favicon.svg` | Heavier-stroke cut for 16–32 px. Self-theming via `prefers-color-scheme` (`#17151F` ink / `#F4F1FA` on dark, accent `#7C3AED`/`#8B5CF6`). |
| `avatar.svg` / `avatar.png` | 512 px org avatar on the dark tile `#17151F`. |

Colors come from the portal design system (`--primary`,
`src/main/frontend/src/index.css`): violet `#7C3AED` (light) / `#8B5CF6` (dark).
Geometry lives on a 48×48 grid, stroke width 4, round caps.
