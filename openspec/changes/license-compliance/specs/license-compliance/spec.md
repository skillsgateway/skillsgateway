# license-compliance Specification

## Purpose

License compliance for ingested skill content: deterministic license
detection at ingestion through the standard vetting chain, an org-level
allow/ban policy whose violations flow through the standard finding, waiver
and approval-gate path, unknown/missing license as first-class detectable
states, and the per-snapshot license report endpoint alongside the SBOM and
content inventory surfaces.
