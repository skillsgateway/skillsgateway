## Not run here (environment) — must be green before merge

- **`./mvnw clean verify`** — needs Docker/Podman (Arconia dev-service Postgres,
  packaged jar). No Java, API or persistence code changed in this PR, so nothing
  in the Java surface is affected; the UI gates it wraps (`tsc`, `lint`, vitest)
  were run directly above.
- **`pnpm e2e`** — needs Docker + the mock OIDC IdP and a running gateway. The
  Playwright spec (`e2e/portal.spec.ts`) **was updated** for the new UX: the
  snapshot review actions moved into each marketplace row's expandable region, so
  every test that ingests/approves now calls `expandMarketplace(page, name)` and
  scopes to `page.getByRole("region", { name: 'Snapshots of {name}' })`
  (the region added on `MarketplaceSnapshots`) instead of `[data-slot=card]`.
  SVC_GW_0018/0026/0036/0042/0047/0055/0078/0079/0082/0097 exercise these paths.
- **`reqstool status local -p docs/reqstool`** — needs the Java `@Requirements`
  annotations generated by `./mvnw clean`, so it cannot complete without the Java
  build. The frontend half (`reqstool:tags`) regenerated cleanly (above), and no
  requirement was added or changed, so the requirement/SVC graph is unchanged.
