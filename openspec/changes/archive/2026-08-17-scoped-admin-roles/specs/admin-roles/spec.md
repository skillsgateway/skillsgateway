# admin-roles Specification

## Purpose

Delegated administration of the web surface: the admin/approver/auditor role
model with per-marketplace approver scoping, deny-by-default enforcement at
the REST API once enabled, the auditor's read-only guarantee, and the audited
grant lifecycle with configuration-bootstrapped admins.
