# forge-mirror Specification

## Purpose

An optional, read-only copy of approved content on an external code host, kept
up to date by reconciling against what the facade serves, so that people can
browse and search it there. It is a visibility convenience and never a serving
surface: nothing about approval, revocation, authorization or what the facade
serves depends on it, revocation reaches it without being gated on it, its
divergence from the served content is reportable and bounded rather than
open-ended, and a reconciliation refuses to act at all on a served reference set
the system's own records contradict.
